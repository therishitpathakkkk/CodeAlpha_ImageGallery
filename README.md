# 📸 RISHIT'S GALLERY

A modern and responsive image gallery website built using **HTML, CSS, and JavaScript** as part of my **CodeAlpha Frontend Development Internship**.

The gallery focuses on presenting photographs through a clean, dark and modern visual interface with interactive filtering, dynamic rendering and a lightbox experience.

## ✨ Features

- 🖼️ Dynamic image rendering using JavaScript
- 🔍 Category-based image filtering
- 💡 Interactive image lightbox
- ❌ Close lightbox using close button
- 🖱️ Close lightbox by clicking outside the image
- 📱 Responsive design for different screen sizes
- 🍔 Responsive mobile navigation menu
- ✨ Smooth transitions and hover effects
- 🏷️ Image category and title display
- 🔢 Dynamic image numbering
- 🔗 Social media links in footer

## 🗂️ Gallery Categories

The gallery interface includes the following categories:

- All
- Nature
- Travel
- People
- City
- Architecture

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Remix Icon
